# Gate 合约回测原型

这是一个只读取 Gate USDT 本位永续合约数据的 Python 回测工具。行情、合约规格和历史资金费率通过 Gate 公开接口获取，因此回测不需要 API Key。网页顶部还可选填 Gate APIv4 Key，以只读方式查看合约账户摘要和个人手续费；程序不会创建或提交订单。

## 用网页操作

在这个文件夹打开终端，运行：

```bash
python3 app.py
```

然后在浏览器打开 `http://127.0.0.1:8765`。网页里可以点选 BTC、ETH、SOL、TSLA、AAPL、NVDA，设置日期和 5 分钟、15 分钟、1 小时或 4 小时周期，按“开始回测比较”查看结果，并下载 CSV。结果会把数据前后等分进行资格检查；只有总样本至少 50 笔、利润因子超过 1.10、最大回撤不超过 10%，且前后两段都盈利，才标记“允许模拟”。当前提供历史回测；实时模拟盘和 AI 信号还没接入。

页面顶部可以测试 Gate API 只读连接。只创建 APIv4 Key 并开启“永续合约—只读”权限；实盘和测试网密钥不能混用。测试网适合确认连通性；要读取真实余额和个人费率，请选“实盘账户（只读）”并使用实盘 Key。浏览器会把 Key 与 Secret 交给本机服务完成签名，只读取 USDT 合约账户摘要和当前合约列表对应的个人费率，随后清空输入框；程序不会把密钥写入配置、缓存、日志或回测结果。连接成功后，回测会按合约分别应用个人 Taker 费率；未读取到的合约使用页面备用费率。K 线、合约规格和历史资金费率仍来自 Gate 公开行情接口。

## 运行

需要 Python 3.9 或更新版本，不需要安装第三方包。

```bash
python3 gate_backtest.py \
  --contracts BTC_USDT,ETH_USDT,TSLA_USDT,AAPL_USDT \
  --interval 15m \
  --start 2026-09-01 \
  --end 2026-09-08 \
  --strategy all
```

日期按 UTC 解释，`--end` 不包含当天。行情和资金费率缓存到 `.cache/`；交易明细 CSV 与汇总 JSON 写入 `results/`。每个合约和策略单独回测，各自从同一初始资金开始，不代表共享资金的组合回测。

本次修正前生成的 290 个 CSV/JSON 已保留在 `results/archive_pre_contract_multiplier_fix_20260913/`。旧版本没有按 Gate 合约乘数换算张数，旧收益与仓位数值不应和新回测混用；重新运行后，新结果会写入 `results/`。

可调整的参数包括初始资金、每笔风险比例、名义杠杆上限、手续费和滑点。当前默认值（10,000 USDT、每笔 0.5% 风险、1 倍杠杆、单边 taker 手续费 7.5 bps、单边滑点 2 bps）只是可运行的比较基线，需要按你的账户费率和目标成交规模校准。

## 对比的基线策略

- `trend`：EMA(20/50) 金叉/死叉。
- `breakout`：收盘价突破前 20 根 K 线高点/低点。
- `mean_reversion`：收盘价从布林带外重新穿回 20 根均线的两倍标准差通道。
- `trend_pullback`：用至少 200 根完整的趋势周期判断 EMA(50/200) 方向；收盘重新穿回 EMA(20) 时顺势进场。

止损按信号结构设置，并在结构价外留 ATR(14) 的 0.25 倍缓冲：趋势策略使用近期 20 根 K 线摆动极值；突破策略使用被突破的 20 根区间边界；均值回归使用回归信号前后两根 K 线的极值；趋势回踩使用本次回踩段的摆动极值。止盈仍按实际入场价到止损价的距离设为 2R。信号在 K 线收盘后生成，下一根 K 线开盘进场；若开盘已越过结构止损，则跳过该信号；开盘跳空扩大止损距离时，按实际入场价重新计算仓位和止盈价。若一根 K 线同时触及止盈和止损，按先触及止损处理。

仓位按结构止损触发后的预计亏损（包含往返手续费与滑点）反算；页面/命令行的单笔风险比例是上限，不要求每笔用满，并同时受名义杠杆上限、合约张数精度和最小下单张数约束。计算盈亏、手续费、资金费和名义仓位时，按 Gate 合约乘数换算张数价值。事后平均盈利单/亏损单比值仅作结果统计，与每笔预设 2:1 分开报告。止损跳空可能造成超过预算的损失。

## 已知边界

- 目前按命令行指定的合约逐个测试；“热门币”还没有做历史成交额排名，避免用今天的热门列表回看过去造成幸存者偏差。
- 程序读取 Gate 公布的合约乘数和最小下单量，但还不模拟维持保证金、强平、盘口深度和资金费率事件发生在同一根 K 线内的精确先后。因此结果适合比较策略原型，不是实盘收益预测。
- 最大回撤基于逐根 K 线收盘的盯市权益；股票代币在无成交时可能有零成交量 K 线，程序不会在这些 K 线上新开仓。
- 目前的资格检查是简单的前后两段验证，还没有完整滚动验证，也没有 AI 信号或实盘交易。

```bash
python3 -m unittest -v
```
